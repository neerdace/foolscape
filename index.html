Everything a page needs

TAB / ENTER

Format-aware typing

ABOUT

Why "Foolscap"

Foolscap is the old name for the long sheet of paper that scripts and legal drafts were once written on — this is that page, rebuilt for the screen and set in whatever language your story is told in.

Scripts you write here stay in this browser tab for the length of your session. Use Export .txt for a plain draft, or Print / Save as PDF from the editor toolbar for a properly paginated copy — do this before you close the tab, since nothing is saved to a server.
